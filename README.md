# smallspacecompass.com

Static site, published from `docs/` (GitHub Pages, CNAME `smallspacecompass.com`).

- Source: `build/build.mjs` + `src/content/*.mjs` → `node build/build.mjs` regenerates `docs/`.
- Browser code (vanilla JS + SVG): `docs/assets/js/` – `geometry.js` (collision, door swings, distance field, widest route/A*, delivery rotation), `render.js`, `planner.js`, `delivery.js`, `storage.js`, `site.js` (ad slots, consent-gated GA4, interim statistics window `ssc-stats` while Google's CMP shows no message – see the comment block in `site.js` and `/privacy/#interim-statistics`).
- Reference table (`/reference/`): rows and sources live in `docs/assets/js/refdata.js` – one row per figure, read in the primary document, with section, scope and the retrieval date `RETRIEVED`. `conv` marks the column that is our own conversion. Add a row only after reading the document; guides link to rows with `ref('row-id', 'text')` from `src/content/common.mjs`, and `npm run check` fails on a link to an unknown row.
- Clearance Check (`/tools/clearance-check/` and the home page): logic in `quickfit.js` (pure, tested), UI in `quick.js`. Every reference width it compares with cites a row of `refdata.js`; a test checks that the width really appears in that row.
- Share links: the Clearance Check and the delivery check write the entered numbers into the URL fragment (`#…`) only when “Copy link” is pressed, read them on load through a whitelist (`decodeQuick`, `deliveryFromFragment`) and then remove the fragment from the address bar. See `/privacy/#plans`.
- CSV exports go through `csv.js` (cells starting with `= + - @` are neutralised).
- Dates: pages changed in a revision carry `updated: true` in their source object and get the new `lastmod` / `dateModified` / review date; untouched pages keep the old one (`MODIFIED`, `MODIFIED_NEW` in `build/build.mjs`).
- Ad slots: fill the slot IDs in `docs/assets/js/site.js` (`ADSENSE.slots`). Empty ID = no slot rendered, no space reserved. The AdSense loader sits statically in the head of every indexable page (after the consent defaults); `site.js` never loads it a second time. Slots only on guide and tool pages; the browser test forces every slot visible and requires 150 px to buttons, inputs and summaries.
- Layout notes: `src/content/layout-notes.mjs` (`body` plus `more`: variants, mistakes, the 12 in smaller check, adapting, measurements).
- Tests: `npm test` (geometry, every published plan example, reference table, Clearance Check, share links, CSV), `npm run check` (pages; guides are gated on substance – own figure, data table, tool/reference link – not on 900 words), `PLAYWRIGHT=/opt/npm-tools/node_modules/playwright node tests/tools-new.mjs` (new tools, reference table, hostile input, every in-page anchor of every sitemap page), `PLAYWRIGHT=/opt/npm-tools/node_modules/playwright node tests/consent.mjs` (consent flow with stubbed CMP, incl. the interim statistics window; `CHROME=` overrides the browser path), `PLAYWRIGHT=/opt/npm-tools/node_modules/playwright node tests/browser.mjs [paths|all]` (390/1366 px).
- Fonts self-hosted (Archivo, IBM Plex Mono, OFL in `docs/assets/fonts/`).
- Old URLs: see `REDIRECTS.md`.
